# 个人影像作品集 · 维护说明

这是一个纯静态网站：**代码归代码，内容归内容**。日常改文字、换视频、加作品，只需要编辑 `data/works.json` 这一个文件，不用碰 HTML / CSS / JS，也不用命令行。

线上（Vercel）：在 GitHub 网页打开这个文件 → 改 → 保存（Commit）→ Vercel 自动重新发布，1–2 分钟生效。

## 文件都是干什么的

| 文件 | 作用 | 要不要改 |
|---|---|---|
| `data/works.json` | **所有内容**：站名、About、邮箱、社媒、分类、每条作品 | ✅ 只改这个 |
| `assets/img/` | 封面图、`stills/` 里的影片静帧、首屏兜底图、About 区个人照片 `portrait.jpg` | ✅ 换图时往里放文件 |

| `index.html` | 首页骨架（首屏 / WORK / 视图切换 / 网格 / About / 页脚） | ❌ 骨架 |
| `work.html` | 详情页骨架 | ❌ 骨架 |
| `assets/css/style.css` | 黑底、字体、网格列数、动效 | ❌ 骨架 |
| `assets/js/app.js` | 渲染逻辑、播放器、灯箱 | ❌ 骨架 |

| `site.hero.poster` | 首屏静态兜底图（手机 / 省流量 / 视频加载失败时显示） |

| `site.hero.videoGlobal` / `videoCn` | 首屏短片的**海外源 / 国内源**直链。线上按访客地区自动选：大陆优先 `videoCn`、其它优先 `videoGlobal`；`videoCn` 留空时大陆也走 `videoGlobal`。见 `DEPLOY.md` |

| `site.view.remember` | `true` 记住访客上次选的视图；`false` 每次进站都回到 `default` |

| `works[].title` | 卡片标题（大图流叠在封面左下、网格在图片下方）+ 详情页大标题 |

| `works[].cover` | 首页卡片封面（大图流按原比例整张显示、网格统一裁成 4:3）+ 单视频详情页的播放器封面 |
| `works[].aspect` | 详情页播放器的画幅比例 + 大图流封面的高度，见下方「画幅比例」；**只是布局参数，页面上不会显示成 `5:4` 这类文字** |
| `works[].video` | 详情页视频：Vimeo / YouTube 链接或 mp4 直链 = 1 支片；写成数组 = 同一项目放多支短片，见下方「换视频 / 一个项目放多支短片」与「用 mp4 直链」。这里填的是**本地路径 / 主链接**，本地预览用它 |
| `works[].videoGlobal` / `videoCn` | 同一支片的**海外源 / 国内源**直链，线上按访客地区自动选（`videoCn` 留空时大陆走 `videoGlobal`）；某源加载失败自动换另一个。多支片系列则在 `video` 数组的每一项里填 `urlGlobal` / `urlCn`。访客可用网址 `?r=cn` / `?r=global` / `?r=auto` 手动切换。详见 `DEPLOY.md` |
| `works[].note` | 详情页一句话阐述 |
| `works[].stills` | 详情页的**影片静帧组**（从成片里截出来的帧，不是分镜、不是幕后花絮）；数组顺序 = 展示顺序，点开是图片灯箱；**空数组 `[]` 时整段自动隐藏** |

## 常见操作

### 点 CONTACT 会发生什么

导航的 `CONTACT` **不是页内跳转**，点下去会在右上角弹出一个小面板：

- 显示邮箱地址（点它本身仍是 `mailto:` 发邮件）
- **Copy address**：一键复制，按钮短暂变成 `Copied`
- **Open mail app ↗**：调用系统默认邮件软件新建邮件
- 底部一行说明：如果点了没打开，就复制地址手动发

为什么要多这一步：`mailto:` 要交给操作系统处理，很多访客（尤其用网页版 Gmail 的人）以及站内嵌预览里点了**完全没反应**。面板保证至少能立刻看到邮箱、能复制。面板可以用 `Esc`、点 `×`、点页面空白处或再点一次 CONTACT 关掉；点「打开邮件 App」后面板**故意不收起**，没反应时还能改点复制。

面板是 `app.js` 自动生成的，首页和详情页共用一份；改邮箱只改 `works.json` 的 `site.email`，三处链接和复制内容会一起变，不用碰代码。

### 首屏大字的字体

首屏 `VALJEAN` 用的是 **Roboto Condensed**（参考站 lonnwave.com 首屏同款字体），字重 900、字距收紧、全大写；字号由 `app.js` 按站名长度自动算，让大字始终撑满首屏宽度。字体文件放在 `assets/fonts/`，**本地自托管、不依赖 Google Fonts 外链**，离线也能正常显示。

想改字重（更细 / 更粗）或换字体，要动 `style.css` 的 `.hero-title`，属于**改骨架**；只改站名文字仍然只动 `works.json`。

### 首页展示方式：纵向大图流 / 网格

作品区右上角是 `ALL` 文字 + 一排两个圆底小图标，三者绑定成一组，访客可以自己切换。**WORK 标题与这组工具在任何窗口宽度下都保持同一行**，缩窄窗口不会错行：

- `ALL`：**静态标签**，表示当前展示的是全部作品，不可点击、不起筛选作用；样式沿用原分类按钮（11px、700、大写、灰色），和图标一样用固定像素，**不随窗口缩放变大变小**。
- 左边「大图流」：封面一张接一张纵向排列，**左右各留一条与全站统一的内边距、片与片之间也留一段克制的间距**（不再贴边、不再无缝）；每张按它自己的 `aspect` 原比例显示（16:9 的矮一点、5:4 的更高），不裁切、不拉伸。片名 / 客户 / 年份直接叠在封面底部：左下是 `片名 | 客户`，右下是白底年份小标签（参考 lonnwave.com 的形式，字体与配色适配了本站黑底风格）。
- 右边「网格」：3 列卡片（平板和手机都是 2 列），每张按 4:3 统一裁切，信息仍在卡片下方，一屏能看更多。

**默认是纵向大图流**，由 `site.view.default` 决定。想改成默认网格，只要把它改成 `"grid"`：

```json
"view": {
  "default": "grid",
  "remember": true
}
```

- `remember: true`：访客选过一次会记住，下次进站还是他选的那种。
- `remember: false`：不管访客怎么点，每次重新打开网站都回到 `default`。
- 切换会同步到网址 `?v=grid` / `?v=flow`，可以直接把某种视图的链接发给别人；网址里的 `v` 优先级最高。
- 首页**没有分类筛选**，只有一个静态 `ALL` 标签，作品始终全部显示；分类名只在详情页元数据里出现。
- 切换只影响首页排列，卡片内容、点进去的详情页、静帧灯箱都不变。

> 网格的**列数与 4:3 裁切**、大图流的**四周留白数值**、封面信息叠加、顶部导航的**加粗与悬停气泡**都写在 `style.css` / `index.html` 里，属于骨架；只改默认展示方式不用碰它。大图流用的比例取自每条作品的 `aspect`，改比例只改 `works.json`。

顶部导航 `VALJEAN / WORK / INFO / CONTACT` 和视图切换按钮，鼠标停上去会弹出一条简短气泡说明跳到哪（如 `Home`、`View work`、`Grid view`）。提示文字写在 HTML 的 `data-tip` 属性里，想改措辞属于改骨架。首屏底部原本的 `Selected moving images…` 与 `Scroll ↓` 已按要求移除。

### 页面文案与字重

- 作品区标题是 `WORK`，About 区小标题是 `( About me )`，都写在 `index.html`，想改措辞属于改骨架。
- 详情页静帧组的小标题 `Selected frames` **写在 `works.json` 的 `site.labels.stills`**，改一个词就行，属内容操作；页面会自动显示成大写 `SELECTED FRAMES`。备选：`Film stills`（行业通用）、`Frames`（最短）、`Stills`。
- **全站所有小字段统一 700 字重**（和顶部导航一致）：`( About me )`、城市 / 身份、About 正文、能力清单、`Let's talk`、邮箱、`Copy Email`、页脚站名与社媒，以及详情页的 `← All work`、元数据、`Next work`、播放器小标题、联系面板与悬停气泡。
- **两个作品大标题（详情页片名、`Next work` 片名）用 500（Medium）**：已经加粗，但比字段的 700 轻一档，仍和大字段拉开层级。选 500 而不是 600，是因为本机 Helvetica Neue 的 600 与 700 会落到同一套 Bold 字形，看不出"细一些"；要调整粗细改 `style.css` 的 `.detail-title` / `.next-title`。
- 详情页**不显示画幅比例**（`5:4` 之类），卡片上也没有比例角标；播放器下方**没有任何状态文字**。视频真的加载失败时，只会在画面底部出现一行错误提示。`aspect` 字段仍必须填，它决定播放器留白与大图流封面高度。

### 换视频 / 一个项目放多支短片

`video` 有两种写法，**想放几支短片就写几项**，顺序就是详情页从上到下的顺序。

**只有一支片**（写一条链接就行，和以前完全一样）：

```json
"video": "https://vimeo.com/123456789"
```

**一个系列有好几支短片**（写成数组）：

```json
"video": [
  { "url": "https://vimeo.com/111111111", "label": "Film 01", "aspect": "16:9", "poster": "assets/img/series-a-01.jpg" },
  { "url": "https://vimeo.com/222222222", "label": "Film 02", "aspect": "2.39:1", "poster": "assets/img/series-a-02.jpg" },
  { "url": "https://vimeo.com/333333333", "label": "Film 03", "aspect": "9:16", "poster": "assets/img/series-a-03.jpg" }
]
```

也可以偷懒只写链接数组，其余全部跟随作品级设置：

```json
"video": ["https://vimeo.com/111111111", "https://vimeo.com/222222222"]
```

数组项里每个字段都可省略：

| 字段 | 不写时会怎样 |
|---|---|
| `url` | 显示占位播放器；填上链接后自动变成真播放器 |
| `aspect` | 跟随作品级 `works[].aspect`；写了就按这一支自己的比例留白，不拉伸 |
| `poster` | 跟随作品级 `works[].cover`；建议每支各截一帧填自己的封面 |
| `label` | 不显示小标题；填了只作为平级的章节名，**不产生主次层级** |

要点：

- **首页网格永远只占 1 张卡片**，卡片数 = 项目数，不等于视频数。点进详情页才会依次看到这几支短片。
- 加一项 = 自动多一个播放器，删一项 = 自动少一个，改顺序 = 换个排列。全程只改 `works.json`，不用碰代码。
- 多支短片时播放器上方会自动出现一行极小的 `01 / 03` 序号，纯计数、平级，不区分主次。
- 当前 `MOLLY TEA x YVMIN` 就是真实示例：首页只占 1 张卡，详情页里 2 支短片并列，各自用自己的封面。
- 每个播放器**独立懒加载**：访客点哪一支的封面才加载哪一支，不会一次下载全部视频。
- 支持 `vimeo.com/...`、`player.vimeo.com/...`、`youtube.com/watch?v=...`、`youtu.be/...`，程序自动识别并生成播放器。
- 外链要确认允许第三方网站嵌入、不是私密片、没有地区限制，否则详情页会黑屏。

### 用 mp4 直链（自托管片库 / 本地预览）

`video` 也可以直接填一条视频文件地址（`.mp4` / `.webm` / `.mov`），播放器会自动改用浏览器原生 `<video controls>`，不再生成 Vimeo / YouTube 的 iframe：

```json
"video": "https://your-r2-domain.com/film-01.mp4"
```

- 本地想看真实片子：把 mp4 放进 `assets/video/`，写成 `"assets/video/film-01.mp4"` 即可。该目录已被 `.gitignore` 排除，**视频不会进 GitHub 仓库**。
- **当前 8 条作品的 `video` 全部指向 `assets/video/stream/*.mp4`，只用于本机预览**。它们是从 Downloads 原片无损搬移索引（faststart）后「能边下边播」的版本，画质与原片完全一致；原片本体没被改动。索引写在文件尾的 mp4 必须先做这一步，否则浏览器要等整部片子下完才肯播。
- 点封面会**立刻开始播放**（不需要再点一次播放键）；播放器下方平时不显示任何状态文字，只有加载失败时画面底部会出现提示；同一详情页点第二支短片时会自动暂停第一支。
- **上线时别把本地路径带上去**：传到片库（R2 / Stream）拿到 https 直链，或直接换成 Vimeo 链接，改回 `works.json` 就行。否则部署后的详情页视频会是坏的。
- 正式上线仍优先 Vimeo（自动多码率、拖进度条顺、零运维）；mp4 直链更适合自托管片库或临时看效果。

### 换封面 / 换影片静帧

现在用的是你给的指定封面和成片截帧，已从 PNG 压成 JPG：**271 MB → 16.1 MB**，全部放在仓库里。

| 内容 | 位置 | 命名 |
|---|---|---|
| 每条作品一张封面 | `assets/img/cover-wXX.jpg` | `w02` 系列另有 `cover-w02-long.jpg`（长片）和 `cover-w02-short.jpg`（短片），分别填在 `video[0].poster` / `video[1].poster` |
| 每条作品 5–6 张影片静帧 | `assets/img/stills/wXX-01.jpg` … | 数字就是展示顺序，也是灯箱翻页顺序 |

换图步骤：

1. 把新图压成 JPG（封面长边约 2000px、静帧约 1600px，质量 80 左右），按上表命名放进对应目录。
2. 同名覆盖上传 → 连 `works.json` 都不用动；换了文件名 → 把 `cover` / `stills` / `poster` 里的路径改掉。
3. 想加减静帧：直接改 `stills` 数组，删一项少一张、加一项多一张，灯箱计数自动跟着变。

两个注意点：

- 封面在**网格视图**统一裁成 4:3，但**大图流按 `aspect` 原比例整张显示**，所以封面图务必跟片子真实画幅一致（当前 6 条 16:9、2 条 5:4，全都对得上）。
- 静帧是从成片截出来的，构图、片中字幕和品牌字都在画面里，**详情网格按作品原画幅完整显示（`object-fit: contain`），不裁切**；点开的灯箱同样显示整张。这是专门给静帧改的，别再改回 4:3 统一裁切。

> 命名说明：分镜（Storyboard）是**开拍前**画的镜头规划草图；这批是**成片里挑出来的帧**，行业里叫 Film stills / Selected frames，所以小标题叫 `Selected frames`，不叫 Behind the scene，也不叫 Storyboard。`Behind the scene` 指拍摄现场花絮照，和这批图不是一回事。

### 加一条作品

复制 `works` 数组里任意一整个 `{ ... }`，粘贴到数组末尾（记得前一个后面加逗号），改掉 `id`、`title`、`cover`，其余字段按需填。

保存后首页会**自动多一张卡片**，同时**自动多出一个详情页** —— 不用新建页面文件。

`id` 用小写英文 + 连字符，例如 `"winter-light"`，它会成为详情页网址 `work.html?w=winter-light`。

### 分类名（只显示在详情页）

首页已去掉分类筛选、全部作品一起展示。`categories` 现在只用于详情页元数据：改 `label` 就改详情页上显示的类别名；作品 `category` 填了但 `categories` 里没有对应项时，详情页不显示分类。增删分类不会改变首页卡片。

### 画幅比例怎么填

`aspect` 同时决定两处：详情页播放器是横是竖（**不会拉伸画面**，四周留黑），以及**大图流视图里这张封面的高度**（宽度铺满、高度按这个比例算）。它**不会显示成文字**给访客看，纯布局参数。填错的话大图流会留多余空白，所以务必跟片子真实比例一致：

| 值 | 用途 |
|---|---|
| `16:9` | 常规横片 |
| `2.39:1` | 宽银幕 |
| `1:1` | 方形 |
| `9:16` | 竖片（手机竖屏） |

也可以写小数，例如 `"1.33"` 表示 4:3。

### 换首屏短片

首屏短片是纯背景装饰，要求 **静音 + 循环 + 无控件 + 自动播**，所以不能用 Vimeo / YouTube，得用自托管的 mp4：

1. 准备一段 8–20 秒、1080p 以内、压成 H.264 的 mp4（控制在 5–15 MB）。当前用的是 `首页.mp4` 压出来的 `assets/video/hero-loop-small.mp4`：**完整保留 19.6 秒**，1280×720、约 5.7 MB、去了音轨（页面本来静音循环），画质逐帧比对与原片一致。
2. 上传到片库（Cloudflare R2 / Stream 都行），拿到一条直链。
3. 把链接填进 `site.hero.video`，例如 `"https://your-r2-domain.com/hero-loop.mp4"`。

页面会自动创建 `<video autoplay muted loop playsinline>`；**加载失败、手机省流量或没填链接时，自动显示 `site.hero.poster` 这张静态图**，不会黑屏。想换短片，直接按同名覆盖上传即可，连 `works.json` 都不用动。

### 首屏是一张固定 16:9 的海报（2026-11-16 定稿）

首屏 = 16:9 视频画面 + 上下留白，`VALJEAN` 与下方一行小字叠在画面上。视频、大字、间距、**上下留白全部按视口宽度等比缩放**——整张海报（含黑边）放大缩小时一起等比，不出现「桌面一套 / 手机另一套」。

- `--hero-pad:3.5vw`；首屏高度 = `视口宽 × (0.5625 + 0.07)`。实测留白 1920 → 各 67px、1440 → 各 50px、1024 → 各 36px、800 → 各 28px、390 → 各 14px，**全程严格等比**。
- 小字和导航有**可读下限**：tagline 等比但最小 10px；顶部导航固定 10–12px、不参与缩放。否则手机等比后只剩约 3px。
- 想换留白比例，只改 `style.css` 里 `.hero` 的 `--hero-pad`，其余不用动。

### About 区按三分线排版（2026-11-16 定稿）

About 区和首屏同构，也是一张**按视口宽度等比**的固定版式海报：以整幅画面宽为基准分三栏，**照片中心压在第一条竖直三分线（1/3）上**，文字块落在照片右侧的第二栏，能力清单用 `margin-top:auto` 推到底，使**城市行顶边与照片顶边齐、能力清单底边与照片底边齐**（实测误差 0–1px）。

- 照片尺寸 `19vw`、文字块宽 `38vw`、该区高度 `50vw`、各段字号 / 间距全用 `vw` + 可读下限，窗口缩放时整套一起等比。
- `( About me )` 小标题在照片上方偏左（第一栏内）；小字有下限（正文 `max(13px,1.5vw)`），避免窄窗口下不可读。
- **手机（≤640px）不贴三分线**：改回单列居中流式布局（照片居中、文字在下方），否则 1/3 线会把照片挤得极小。这是唯一一处不参与等比的断点。

换图：把新照片放进 `assets/img/`，改 `site.portrait` 的路径即可（当前 `assets/img/portrait.jpg`，900×900、约 279 KB）。**删掉 `site.portrait` 或留空字符串，整块照片自动隐藏**，About 区回到纯文字版。

想改照片落点（从 1/3 挪到 2/3 或居中）、照片尺寸、文字块宽度或齐平方式，都属于改骨架（在 `style.css` 的 `.info` / `.info-portrait` / `.info-body` 里）。

> 注意：mp4 **不要放进这个仓库**。GitHub 仓库只存代码和图片，`.gitignore` 已经把整个 `assets/video/` 目录排除掉了（包括本地预览用的软链接、重排版和压缩版）。

## 本地预览

因为页面要读取 `works.json`，需要用本地静态服务器打开（直接双击 HTML 会被浏览器的本地文件限制挡住）：

```bash
cd 网站目录
python3 -m http.server 8000
```

然后浏览器访问 `http://localhost:8000`。线上部署不需要这一步，Vercel 会正常提供静态文件。

## 上线（Vercel + 自定义域名）

1. 把这个目录推到 GitHub 仓库。
2. Vercel → New Project → 导入该仓库 → Framework 选 **Other / Static**，直接 Deploy。
3. 在域名注册商买好自己名字的 `.com`，在 Vercel 项目 Settings → Domains 添加它。
4. 按 Vercel 提示在注册商加一条 DNS 记录（CNAME 或 A）。解析到境外服务器**不需要 ICP 备案**。

## 哪些改动属于「改骨架」

下面这些不在 `works.json` 里，改起来要动 CSS / JS，建议找人帮忙，别自己硬改：

- 网格列数、封面裁切比例改成瀑布流、大图流的四周留白数值、静帧网格的列数与原比例完整显示方式
- 配色、字体、字重（全站字段 700 / 作品大标题 500 / 首屏站名 900）、动效
- `WORK` / `( About me )` 等页面固定文案
- 顶部导航的悬停提示文案、封面叠加信息的排版、联系面板的样式与文案
- 新增页面类型（博客 / 商店 / 密码页）、多语言切换
- 灯箱交互、播放器行为、首屏版式（16:9 固定画布比例、`--hero-pad` 留白比例、tagline 最小字号）、About 区三分线落点 / 等比尺寸 / 照片与文字齐平方式

其余所有内容类改动，都在 `works.json` 里完成。**「一个详情页放多支短片」和「大图流 / 网格视图切换」都已内置，属于内容操作、不属于改骨架**：前者把 `video` 写成数组，后者改 `site.view.default`，都只动 `works.json`。
